# FanGraphs Library — What is WAR?

## 基本資訊
- 作者：Piper Slowinski；發表：2010-02-15（內容含後來的更新）
- 原始檔：`raw/articles/2010-02-15_fangraphs_what-is-war.pdf`；擷取日期：2026-11-12

## 核心論點
1. [[war|WAR]] 把球員對球隊的總貢獻濃縮成一個數字，回答「如果他受傷、改由隨手可得的小聯盟球員替補，球隊會損失多少勝場」。
2. WAR 是估計值：6 WAR 的球員實際可能介於 5.0 到 7.0。6.4 和 6.1 無法區分，6.4 和 4.1 則有把握。
3. 野手：(Batting + Base Running + Fielding + 守位調整 + 聯盟調整 + 替補水準) ÷ RPW。投手：以 FIP（含內野高飛球）為基礎，經球場調整、依局數縮放。
4. fWAR（FanGraphs）、rWAR／bWAR（Baseball-Reference）、WARP（Baseball Prospectus）框架相同、替補水準相同，但打擊、守備、投球的估算方法不同。
5. 不確定性最大的地方：野手的守備與守位調整；投手的場內球責任歸屬。FanGraphs 另提供 RA9-WAR。
6. 解讀：先發野手與先發投手平均約 2 WAR；板凳球員 0～1；後援投手超過 1 就很出色。
7. 每季 1,000 WAR，對應替補勝率 .294；野手 570、投手 430。WAR 不考慮情境、聯盟、球場，可以跨年、跨聯盟、跨球隊比較；可以是負值。
